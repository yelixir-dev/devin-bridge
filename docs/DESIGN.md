# Documentation design

The README banner follows the repository family's Emil editorial treatment.
This contract covers documentation assets, not an application dashboard.

- Canvas/ink: `#28231f`; paper: `#fffdf8`; muted: `#a89f93`.
- Gold: `#b57920`; teal: `#1f6f78`; rust: `#9f4d2e`.
- Banner: 1200 x 300 SVG; opaque ink background; 14 px inset gold hairline.
- Typography: Georgia/Times New Roman serif; italic brand; compact metadata.
- Evidence line: JSON/SSE, function tools, and SWE-2 reasoning levels.
- Attribution page: semantic header/main/article; one readable column; body owns
  scrolling; long source paths wrap. No animation or JavaScript.
- Banner scales proportionally within its host. No external fonts or images.
- Verification: inspect the SVG and attribution HTML at desktop/mobile sizes.

Sources: readme-forge's banner-emil contract and the family's previous design
documents; StyleGallery GUIDE for semantic document order and scroll ownership.
Consumer reference: not applicable to these static documentation assets.
